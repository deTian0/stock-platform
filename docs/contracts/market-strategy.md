# 契约：市场策略（草稿）

> 状态：Draft（M0.2 定稿 A 股表；M5 补美港）

市场差异用 **显式策略表**，禁止在 UI/回测里散落 `if market == ...`。

## A 股（默认，M0–M4）

| 项 | 规则 |
|----|------|
| 交易日历 | 上交所/深交所交易日 |
| 时区 | Asia/Shanghai |
| 交收 | 股票 T+1；细则以回测引擎配置为准 |
| 涨跌停 | 存在；用原始价判断，不用复权价 |
| 代码 | 6 位；北交所号段策略另表 |
| 分钟 K | naive 墙钟，禁止 UTC 入库 |

## 美股 / 港股（M5）

| 项 | 规则 |
|----|------|
| 交易日历 | 各自交易所 |
| 时区 | 美：America/New_York；港：Asia/Hong_Kong |
| 涨跌停 | **无** A 股式涨跌停假设 |
| 交收 | 不套用 A 股 T+1 |
| 代码 | 不进入 A 股 `normalize_symbol` 成功路径 |
