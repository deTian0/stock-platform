# 影子终榜 S4 / S5 选股质量诊断（2026-11-06）

> 状态：**诊断完成，仅证据与建议**。未改 `schools.py` / `round2.py` / `backtest.py` / `cli.py` / adoption_gate 任何逻辑或默认值。处置须签核；改学校口径先写 ADR（ADR [`0093`](../architecture/0093-multi-strategy-shadow-board.md)）。
> 背景：[`multi-strategy-final-board.md`](multi-strategy-final-board.md) §11.5 中，仲裁 A/B 把 S4/S5 放进仓位后，S4 已平仓胜率 11%–17%、均净 −2.3%~−7.7%；S5 胜率 27%–31%、均净 −0.7%~−3.7%。

## 1. 一句话

- **S4（短动量）**：因子在 A 股这个口径下**方向反了**（短期反转）。IC 为负且稳定，五分位单调，反向池为正。T+1/涨停、持有期都不是主因。
- **S5（资金流）**：两层问题。①**实现缺陷**：历史上没有资金流字段，S5 退化为 `min(amount/1e9, 0.8)`，成交额 ≥ 8 亿全部同分，再按代码升序截断，结果 100% 是 `000` 开头的票。②即使按真实成交额排序（对照池 `S5amt`），**大成交额因子本身也为负**。没有发现未来数据。

## 2. 方法与口径

模块：`stock_platform_research.shadow_board.diagnostics`（只读诊断，配单测 `test_shadow_board_diagnostics.py`）。

```powershell
$env:STOCK_PLATFORM_ENGINE_MARKET_DB = "D:/workspace/stock_trading/a-stock-engine/data_cache/market.db"
.venv\Scripts\python.exe -m stock_platform_research.shadow_board.diagnostics --every 1 --out-dir local/shadow/diagnostics
```

- **独立于 Round2 和席位**：每个交易日用回测同一份 `prepare_shadow_frame` → `frame_to_universe` 截面，直接调用 `school_s3_quality / school_s4_short / school_s5_flow`（`top_k=8`），拿 Round1 候选池。
- **对照池**（只在诊断里存在）：`S4inv` = S4 `short` 综合分**最低** 8 只（反向）；`S5amt` = 按原始成交额取前 8（去掉饱和与代码排序）；`RANDOM` = 合格宇宙均匀随机 8 只（种子 `20261106`）。
- **前向收益**：`daily_price` 只有 `close/pct_chg/vol/amount`，**没有 open/high/low**。因此入场按引擎口径用信号日收盘价，`fwd_h = close[t+h]/close[t] − 1`，h = 1/3/5/10/20；另算 T+1 收盘入场的延迟版本。价格用 `compute_features` 的复权重建收盘。
- **超额**：market.db **没有中证 500/沪深 300 指数行**（`000905.SZ` 是个股「厦门港务」，`000300.SH` 不存在）。所以超额相对**当日合格宇宙等权均值**（成交额 ≥ 1000 万、有名称、非 ST）。
- **t 值**：用日均序列计算，并按 `sqrt(h)` 折减重叠窗口，只作量级参考。
- **IC**：每日对 S3/S4 全量综合分和单因子（`rev_chg / vol20 / amount`）与前向收益做 Spearman 相关。
- **退出模拟**：逐票套用引擎退出规则（`rules.evaluate_exit` + 默认 `ExitPolicy` + `CostModel`），不做席位竞争。
- **regime**：`schools.s1_regime_state`（strong 642 / mid 332 / weak 440 天）。
- 区间：2021-01-04 ~ 2026-11-05，逐日。产物 `local/shadow/diagnostics/s4_s5_diagnosis.{json,md}`、候选明细 `s4_s5_candidates.csv.gz`（不提交）。

## 4. 根因判断（逐项）

| 假设 | S4 | S5 |
|------|----|----|
| 因子本身无效 / 反向 | **成立，证据强**。IC −0.10（IR −0.64，75% 的天为负），五分位单调，反向池为正，全 regime、全年份一致 | **成立，证据中强**。真实成交额排序同样为负（IC −0.098，S5amt h=5 −0.68%，t −2.2）；原因（如高关注、拥挤）只是假设，本诊断没有检验 |
| 参数 / 阈值不对 | 次要。问题在方向，不在权重：三个维度里「动量」「量能」各自 IC 都为负 | **实现缺陷，证据确凿**。`score = min(amount/1e9, 0.8)` 在 8 亿处饱和，并列后按 `code` 升序取前 8 → 实际变成「流动性达标里代码最小的 8 只」，与资金流无关 |
| 持有期 / 退出不匹配 | 次要。h=1~20 超额全部为负、且随 h 加深，换持有期救不回来。−8% 止损对 vol20≈4% 的票过紧（76% 止损出场，均 10.8 日），会放大回测亏损，但不是方向问题 | 次要。各 h 同样单调为负 |
| T+1 / 涨跌停冲突（追涨） | **加重，但不是主因**。44% 的入池票近 5 日有涨停，20 日涨了 +45%，属于典型追高。信号日涨停（10.5%）的票会被引擎跳过、买不进；但延迟一日入场超额仍为 −0.99%，所以不是「只买到涨停次日」的问题 | 不显著（信号日涨停 2.9%） |
| 数据口径（缺 OHLC、pct_chg 尺度、amount） | 不是主因。5485 只个股里只有 9 只被判为百分点尺度，已统一归一化；每日涨停中位 41 只，量级合理。缺 open → 无法量化开盘跳空，见 §7 | **没有未来数据**：`amount` 是信号日当天成交额，收盘才入场，PIT。历史上没有 `main_net/fund_flow`，S5 从来没有跑过「资金流」逻辑，回测里的 S5 只是流动性薄规则 |

附带发现（S3）：S3 的 Round1 前 8 只相对等权宇宙**没有超额**（h=5 −0.32%，t −1.9），逐票退出模拟的均净也是 0。但 S3 综合分的全截面 IC 是 +0.067。也就是说，S3 的排序方向大体对，但「取前 8」这个头部没有跑赢等权基准。**假设（未验证）**：头部集中在低波、成交额偏大的票（成交额中位 3.27 亿 vs 随机池 0.93 亿），而等权基准里小票占比高。回测里 S3 的 +0.5%~+0.9% 是否主要来自市场 beta 与退出规则、而非选股超额，本诊断没有拆分，不下结论。

## 6. 建议的下一步实验（参数事先写定，不做搜索）

1. **E1 S4 反转候选（前向池研究，先于回测）**：`S4r` = `short` 综合分最低 8 只，再加硬闸「近 5 日无涨停」和「成交额 ≥ 5000 万」（S4inv 成交额中位只有 0.18 亿，需要防冲击成本）。用本诊断模块的同口径统计 h=5/10 超额与退出模拟，并**分 2021–2023 / 2024–2026 两段**。两段 h=5 超额都 > 0 才进入 E2。
2. **E2 板级回测**：在 `s1_mode=pick` 和 `gate/empty` 下分别跑四个变体：S4 空池、S5 空池、S4+S5 都空、S4 换成 S4r。与 D 及 lvrev 对比夏普、回撤、分校成交。需要新增实验开关（出厂默认不变），属于代码改动，签核后另开一刀。
3. **E3 S5 资金流（等数据）**：只在有 PIT `main_net` 历史后再做，口径 = 按 `main_net / amount`（净流入占比）取前 8，硬闸同上。在此之前不评估 S5。
4. 不做的事：不调 S4 三个维度的权重、不扫止损阈值、不换持有期。这些都改变不了方向，只会增加事后选择偏差。

## 7. 局限与存疑

- **没有 open/high/low**：入场是信号日收盘价（与引擎一致），无法评估开盘跳空和日内涨停打开再封；「次日涨停 6%」只能当作上界参考。
- **基准是等权宇宙，不是中证 500**：market.db 没有指数行。等权基准偏小盘，会让大市值池（S3/S5/S4 的成交额都偏大）的超额偏低。方向结论（S4 vs S4inv、IC 符号）不受基准影响。另外，现有回测 CLI 的 `_index_close` 读 `000300.SH`，库里不存在，所以回测报告的超额列恒为空。**已修（2026-11-06）**：回测改经 F1 `benchmark` 单点解析；库内默认 `000905.SZ` 是个股厦门港务，身份校验 fail-closed，超额标「不可用」并在 `limitations` 写明原因。
- `name` / `industry` 用 fundamentals 当前快照（非 PIT），与回测同一限制。
- 个股 `pct_chg` 最大绝对值约 1943 点，推测是新股首日不设涨跌幅，未逐条核实；`compute_features` 会把单日收益截在 ±60% 再重建收盘，影响可忽略。
- t 值只按 `sqrt(h)` 折减，没有做 Newey-West；S4/S5 结论还有 IC 符号一致性与五分位单调性支撑，不靠 t 值单独成立。
- 对照池 S4inv 是诊断用的伪池，没有经过 Round2 硬闸和真实容量检验，**不能当作已验证策略**。
