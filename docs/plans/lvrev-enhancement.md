# lvrev 增强实验（Round2 二轮过滤 / 大势闸门 / 退出规则）

> 状态：**结果已出（2026-11-06）**——五变体中仅 `trail_tp` 四条标准全过 → Proposed ADR [`0094`](../architecture/0094-lvrev-trail-tp-exit.md) 等签核；其余不通过。通过标准事先登记且未改；出厂默认仍关。
> 背景：多策略影子终榜（ADR [`0093`](../architecture/0093-multi-strategy-shadow-board.md)）全区间回测全面跑输出厂 lvrev（[`multi-strategy-final-board.md`](multi-strategy-final-board.md) §11.5–§11.8）。本计划转而在 lvrev 本身上做三类增强，看能否提高盈利能力。**出厂 lvrev、`W_DEFAULT`、`ExitPolicy()` 默认值一律不改**；所有新开关为实验开关、默认关。

## 1. 变体（共 N = 5 个，参数事先写死，每个只跑一组）

对照基线：出厂 lvrev（`book_replay.screener_entry_provider()` 默认参数 + `ExitPolicy()` 默认），即 §11.5–§11.8 表中「lvrev 基线」列（2021-01-04~2026-11-05：总收益 47.24%、回撤 −18.91%、夏普 0.559、胜率 44.40%）。

| 名称 | 实验 | 规则（固定参数） |
|------|------|------------------|
| `r2` | 1. Round2 二轮过滤 | lvrev 当日候选（已过入口闸门与 0.80 分数地板，按 `composite_score` 降序）当作 S0 候选池，原样送进现有 `round2.apply_round2_set_a`（集 A，出厂 `d` 仲裁与默认常量：ST 剔除、成交额 ≥ `AMOUNT_MIN`=1000 万、涨停密封剔除、单行业 ≤ 2、席位 ≤ 10）。通过者按集 A 顺序交给引擎。缺成交额 fail-closed 剔除。 |
| `regime` | 2. 大势闸门 | 沿用 `schools.s1_regime_state`（流动性达标票中 `close ≥ MA20` 的比例；`< 35%` weak、`≥ 50%` strong、可测行 < 5 为 unknown）。weak / unknown 日不开新仓；**不强卖**已有持仓，持仓照常按出厂退出规则管理。 |
| `tiered_stop` | 3a. 分档止损 | 在出厂退出规则之外追加：持仓峰值收益 ≥ +5% 后，收益回落到 ≤ 0%（保本）即止损；峰值 ≥ +10% 后，回落到 ≤ +5% 即止损。不受 `min_hold` 限制。原 −8% 硬止损不变。 |
| `trail_tp` | 3b. 移动止盈 | 追加：峰值收益 ≥ +8% 后，自峰值回撤 ≥ 5% 即离场。不受 `min_hold` 限制。 |
| `time_stop` | 3c. 时间止损 | 追加：持有 ≥ 20 个交易日且当日收益 < 0 即离场。 |

- 退出类追加规则排在 −8% 硬止损之后、出厂其余分支之前；出厂分支顺序与理由字符串不变。
- 三类实验**各自单独**对比基线，不做组合（组合会增加比较次数）。
- 不做参数搜索：上表数字是起草本文时一次性给定的整数阈值（参考出厂 `target_base=5`、`trail_stop_pct=6`、`stop_loss=8` 的量级），未看任何回测结果。

## 2. 通过标准（四条全部满足才算通过）

- **(a) 分年夏普**：2021–2026 六个自然年中，至少 **4 年** 变体夏普 ≥ lvrev 基线夏普。
- **(b) 收益不集中**：单一年份对「变体相对基线总超额收益」的贡献 ≤ **60%**。
- **(c) Y1 分窗**：Y1 3×1y 分窗（`stock-platform-strategy-adoption` 口径）下，变体通过的窗口数 ≥ 基线通过的窗口数。
- **(d) 最大回撤**：全区间最大回撤不比基线差（变体 `max_drawdown` ≥ 基线 `max_drawdown`，即不更深）。

**多重比较**：本计划共试 **N = 5** 个变体，存在多重比较偏差（从 5 个里挑最好的，本身就会偏乐观）。因此：**任一条不满足即判不通过**；不得事后改标准、不得挑区间、不得调参重跑。通过的变体只起 Proposed ADR 等用户签核；不通过只如实记录结论，不写 ADR。

## 3. 口径（事先定）

- **数据**：只读 `a-stock-engine/data_cache/market.db`；区间 2021-01-04 ~ 2026-11-05（预热 180 自然日）；`initial_capital=50000`、`max_positions=15`、`max_picks_per_day=8`；同一 `book_replay.replay_book` 引擎、同一 `prepare_shadow_frame` 特征帧（含 `amount` / `industry`），名称取 `fundamentals` 当前快照（非 PIT，与影子回测同限制）。
- **分年切片**（同 [`multi-strategy-final-board.md`](multi-strategy-final-board.md) §11.7）：取同一次全区间回放的权益曲线与成交，按自然年切分，不做每年冷启动。2026 年为截至 11-05 的不完整年份，照常计入。年收益 = 当年末权益 / 上年末权益 − 1（2021 年以初始资金为分母）；年内最大回撤、夏普（年化、rf=0、日收益，首日收益相对上年末权益）只用当年数据，公式同 `portfolio.compute_metrics`。胜率、平仓笔数按**平仓日**所在年份归属。
- **(b) 计算**：年超额 = 变体年收益 − 基线年收益；贡献 = 该年超额 / 六年超额之和。若六年超额之和 ≤ 0，(b) 直接判不通过；最大的单年贡献 > 60% 即不通过。
- **(c) 计算**：窗口 = `adoption_gate.build_windows(最后交易日, years=1, count=3)`；全区间特征帧按窗 `slice_window`、每窗冷启动；裁决用现行 `AdoptionRule()` 默认阈值与 `decide_adoption`，候选对同一 lvrev 基线判定。基线的通过窗口数按同一规则把基线自身当候选判定得出。**注意**：`AdoptionRule` 要求夏普至少高 0.05，基线自比较按构造恒为 0/3，因此 (c) 对本计划的约束较弱；照原文执行，另列逐窗裁决供参考，不追加判定条件。
- **超额**：market.db 无任何指数行（`000905.SZ` 等为个股），超额按现有 fail-closed 口径标「不可用」，不以个股冒充指数。
- **对比列**：总收益、最大回撤、夏普、胜率、年换手（`turnover_per_year`）、成交笔数、平均持有日。

## 4. 实现约束

- 不改 `book_replay` 引擎；不改 `ExitPolicy()` 默认值、`evaluate_exit` 出厂分支顺序与理由字符串；不改 lvrev 出厂策略与 `W_DEFAULT`。
- 新开关为实验开关、默认关；不传参时与现状逐位一致，并用单测钉住。
- 执行层 SIMULATE，不引入 live 开关；不写 market.db；回测产物放 `local/`（不提交）。

### 5.5 结论与处置

- **唯一通过：`trail_tp`**（峰值 ≥ +8% 后自峰值回撤 ≥ 5% 离场，不受 `min_hold` 限制）。四条标准全过；起 Proposed ADR [`0094`](../architecture/0094-lvrev-trail-tp-exit.md) 等用户签核。**未改出厂默认**。
- `r2`：二轮硬闸几乎不改成交笔数，全区间略差且回撤更深；2022/2026 也未明显改善。
- `regime`：弱日不开仓反而全面弱于基线（含目标亏损年 2022/2026 的夏普仍低于基线）；Y1 虽 3/3 但 (a)(b)(d) 不过。
- `tiered_stop`：收益与夏普双降、回撤更深。
- `time_stop`：全区间收益更高但胜率崩到 27%、回撤略深，卡在 (d)。

**多重比较**：N=5，从中挑出 `trail_tp` 仍有事后选择偏差；按事先标准它四条全过，故记通过并起 ADR，但签核时应知情该偏差。首轮 `r2` 曾因返回规范化代码导致引擎无法按 frame 原码查价、仓位永不平仓（0 笔成交）——属实现 bug，已修后重跑；**未改参数、未改标准**。
