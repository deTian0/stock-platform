# 影子 S3 学派收益的 alpha / beta 拆解（方向 5）

> 状态：**事先登记**（2026-11-06，跑数前写定，单独 commit）。结果出来后不改方法、不改分段、不改判定标准、不挑区间、不换模型。
> 性质：只读研究，SIMULATE。不改任何学校、仲裁、仓位、退出或出厂默认值；不进终榜。
> 背景：影子终榜历史回测（[`multi-strategy-final-board.md`](multi-strategy-final-board.md) §11.8）中 S3 是唯一实际成交的学派，已平仓均净收益约 +0.48%。问题是这部分收益来自市场 / 风格 beta，还是来自真选股 alpha。

## 1. 问题

S3 Round1 候选（质量 / 防守，`school_s3_quality`，top_k=8）的收益，能否被中证 500、中证 1000、沪深 300 的指数收益及大小盘差解释？解释不了的部分（截距项）才算选股 alpha。

## 2. 数据

- **样本**：信号日 2021-01-04 ~ 2026-11-05，逐日；特征预热自 2020-07-08，与 S4/S5 诊断同口径。
- **Y（学派逐日组合收益）**：每个信号日 `t`，取 S3 Round1 候选（`school_s3_quality`，`top_k=8`，不经 Round2、不经席位与退出规则）等权持有，收益为 `close[t+1]/close[t] − 1` 的等权均值（前复权重建收盘，与诊断 `fwd_1` 同口径）。当日 S3 池为空或无次日收盘的票不计入，该日整天剔除。这是**日度再平衡的池收益**，不是回测账本收益。
- **X（指数）**：经 `stock_platform_research.benchmark.load_benchmark_closes` 单点读取（不绕开，不写 market.db）。市场库无指数行，身份校验后回落补充库 `local/aux_market/aux_market.db` 的已校验指数行（ADR [`0095`](../architecture/0095-aux-market-store.md)）。指数日收益 `r_idx,t = close[t+1]/close[t] − 1`。
  - `r300` 沪深300、`r500` 中证500、`r1000` 中证1000；
  - 大小盘差 `spread = r1000 − r300`。
- 指数为**价格指数**（不含分红），与 §5.6 口径一致。

## 3. 模型与统计

主模型 **M3**（判定只用它）：

`Y_t = α + β₃₀₀·r300_t + β₅₀₀·r500_t + β₁₀₀₀·r1000_t + ε_t`

稳健性（只描述，不参与判定）：

- M1：`Y_t = α + β·r500_t + ε_t`
- M2：`Y_t = α + β₃₀₀·r300_t + β_spread·spread_t + ε_t`

估计与推断：

- OLS，含截距；
- 标准误用 Newey-West（Bartlett 核），滞后阶 `L = floor(4·(T/100)^(2/9))`，`T` 为该回归样本数，每个回归各算各的；
- `α` 年化 = 日截距 × 252（算术）；
- 同时报告各 β 及其 NW t、R²、样本数，以及 r500 / r1000 / r300 之间的相关系数（共线性提示）。

## 4. 分段

- **段 A**：2021-01-04 ~ 2023-12-31；
- **段 B**：2024-01-01 ~ 2026-11-05；
- **全区间**：2021-01-04 ~ 2026-11-05；
- **分年**：2021、2022、2023、2024、2025、2026（至 11-05），只描述，不判定。

## 5. 判定标准（写死）

以 **M3** 为准，三条全部满足，才记为「在本口径下有选股 alpha」：

1. 段 A 的 `α` 年化 **> 0**；
2. 段 B 的 `α` 年化 **> 0**；
3. 全区间 `α` 的 NW t **> 1.5**。

任一不满足，记为「未证明选股 alpha」（不等于证伪：可能是 beta 解释掉了，也可能是样本不足）。

判定之外的描述性结论（例如「收益主要由 r500 / 大小盘差解释」）只能写成描述，不能替代上述判定。

## 6. 局限（跑数前声明）

- Y 是 S3 池的日度再平衡收益，不是回测账本收益（账本含 T+1、退出规则、席位竞争与约 36 日持有）。二者差异不在本次拆解范围内。
- 价格指数不含分红，中证指数的股息率会被算进 α。
- 池只有 8 只票，Y 的噪声较大；NW 处理了序列相关，没有处理截面相关。
- 大小盘差只用 1000 与 300 构造，未用真正的 SMB 因子。
- 没有 open / high / low，入场口径沿用信号日收盘价。

- 不写 market.db；产物 `local/shadow/diagnostics/s3_decomp/` 不提交。
