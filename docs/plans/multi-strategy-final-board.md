> **状态**：MVP + 校富化（2026-11-05）— ADR [`0093`](../architecture/0093-multi-strategy-shadow-board.md)；CLI `stock-platform-shadow-board`；S1/S5 薄规则、S2 DI、digest 只读附录；**不改**出厂 lvrev、不打 tag。  
> **版本基线**：`v4.13.7`（累计发版目标仍 `v4.14.0`）  
> **现行快照**：[`../STATUS.md`](../STATUS.md)  
> **升级路径**：影子链证据 → **Y1 采纳闸门** → 人工签核 → **Y2 落档**；禁止跳过 Y1/Y2 直接改出厂 lvrev。  
> **红线**：执行层 SIMULATE；辩论/LLM 不进绩效；东财仍 `em_get`；不写 `market.db`。

## 0. 一句话

五所学校并行出候选 → **硬** Round2 闸门 → Final Board（带理由/预期）→ **只写独立影子账本**。出厂 lvrev 的 picks / hits / 主绩效 JSONL **逐位不动**，直到 Y1→Y2 证明值得改。

---

## 1. 「不立刻改出厂 lvrev」是什么意思（消除「疑似」）

| 说法 | 含义 |
|------|------|
| **出厂 lvrev** | 日用主链：`score_lvrev` + `W_DEFAULT` + 入口闸门 → 今日推荐 / brief / picks 账本 / 命中追踪 / 主绩效 JSONL |
| **多策略 Final Board** | 另一条**并行观察链**：五校 Round1 → 硬 Round2 → Final Board |
| **≠ 立刻改出厂** | 落地多策略时，**禁止**用 Final Board 覆盖、替换或「合并进」出厂 picks；主链文件与默认权重/闸门保持原样 |
| **何时才可能改出厂** | 影子链跑出可复现证据 → 过 **Y1** `adoption_gate` → 你人工签核 → **Y2** 才允许改生产默认档 |

因此「多策略」= **加一条影子观察链**，不是「把现在的推荐系统换成五校制」。若文档或 PR 写到「更新 picks」，一律读成**影子 picks**，除非显式走完 Y1→Y2。

---

## 2. 影子账本（Shadow ledger）白话定义

**影子账本** = 与生产推荐账本**并列、独立落盘**的一套记录，专门存 Final Board 的候选、理由、预期、过闸/落选原因，以及影子侧绩效/命中。

硬约束：

1. **路径独立**：例如 `local/shadow/...` 或带 `shadow` 前缀的表/文件；**不得**写入现行 picks / hits / 主绩效 JSONL。  
2. **列独立**：若同库同 UI 展示，影子指标必须用**独立列/独立段**（如 `shadowHitRate`），禁止 silently 并进主绩效汇总。  
3. **只读生产**：影子链可读 brief/行情/因子；**写回生产账本 = 禁止**。  
4. **升级唯一门**：影子证据只能喂给 Y1；Y2 签核前，出厂 `W_DEFAULT` / `min_pick_score` / 闸门默认值不变。

## 3. Pipeline

```text
┌──────────── Round1（五校并行）────────────┐
│  S1 宏观/择时     S2 事件/主题              │
│  S3 质量/防守     S4 短线动量               │
│  （lvrev 谱系）    S5 资金流/流动性          │
└──────────────────┬───────────────────────┘
                   ▼
┌──────────── Round2（HARD 闸门）───────────┐
│  合规 / 流动性 / 风控硬闸（fail-closed）     │
│  禁止 soft「凑满 N 只」；空板/短板合法       │
│  同票冲突：规则集 A（硬仲裁）+ 集 B（顾问）  │
└──────────────────┬───────────────────────┘
                   ▼
            Final Board
     （理由 / 持有期 / 触发 / 可证伪预期 / 失效条件）
                   ▼
         独立 Shadow ledger ONLY
                   │
                   ▼（证据够了才）
              Y1 → 签核 → Y2
                   ▼
         （可选）改出厂默认档
```

## 4. 五校（Schools）

| ID | 名称 | 角色（摘要） | 与出厂关系 |
|----|------|--------------|------------|
| **S1** | 宏观 / 择时 | 大环境与仓位时机过滤 | 观察输入；不直接改 `W_DEFAULT` |
| **S2** | 事件 / 主题 | 题材与事件驱动候选 | **禁止**绕过 `FACTOR_LIBRARY` 准入直接塞进 `W_DEFAULT` |
| **S3** | 质量 / 防守 | lvrev 谱系（质量·低波·防守） | 最接近出厂；仍只进影子，除非 Y2 |
| **S4** | 短线动量 | 短持有期动量 | 观察；硬闸后可进 Final |
| **S5** | 资金流 / 流动性 | 流量与流动性结构 | 观察；硬闸后可进 Final |

主题校（S2）新因子必须走既有 **`FACTOR_LIBRARY` + IC/正交准入**；未准入的信号只能标 advisory / 影子特征，**不得**静默进入生产权重。

## 5. 风险分拣

| 类别 | 项 | 处置 |
|------|----|------|
| **必须消** | 静默覆盖出厂 lvrev picks | 禁止；Final **仅**写影子账本 |
| **必须消** | 辩论 / LLM 判决进绩效 | 禁止；恒 `excludedFromPerformance` |
| **必须消** | 影子指标混入主绩效 JSONL | 禁止；独立列/独立文件 |
| **必须消** | Soft Round2「凑满 N」 | 禁止；空板/短板合法 |
| **必须消** | 主题校绕过 `FACTOR_LIBRARY` 进 `W_DEFAULT` | 禁止 |
| **尽量压** | LLM 空话 / 模糊理由 | 结构化字段 + prompt/skill 约束（见根 README「LLM 理由约束」） |
| **接受** | 主题数据缺失 → Final 空板 | 接受；真成运维问题再找替代源 |
| **接受** | A 股题材噪音 / 假突破 / 情绪诱多诱空 | 视为常态，不作「系统 bug」 |
| **接受** | 硬闸导致 Final 空板 | 接受；熊市仍有涨停但需要更高技能——**空板 OK，不是缺陷** |
| **延后** | 主题数据缺失时的备用数据源 | 仅当空板成为真实运维痛点再开 |

## 6. 双轨评分 / 仲裁（Round2 / Final）

目标：同票多校冲突时**以盈利最大化为目的**，但硬约束 fail-closed。

使用 **两套并行** 分数/决策辅助（不是二选一）：

### 规则集 A（推荐基线 · 硬仲裁）

- **内容**：集中度上限（行业/主题/单票）+ **学校优先级仲裁**（确定性规则表）。  
- **角色**：合规、流动性、风控等硬闸的**唯一可覆盖性裁决者**；冲突时 **A 说了算**。  
- **性质**：fail-closed；可单测；不依赖 LLM。

### 集 B（实验 · 顾问）

- **内容**：贝叶斯统计 + LLM 估计胜率与期望（用于排序与解释的数字）。  
- **角色**：**顾问数字**——帮助排序、写理由、做对照实验；**禁止**静默覆盖合规/流动性等硬闸。  
- **性质**：在 **Y1 验证前**标为 experimental / advisory；不得单独决定「是否过硬闸」。

| | 规则集 A | 集 B |
|--|----------|------|
| 可否否决硬闸通过 | 可以（收紧） | **不可以** |
| 可否让未过硬闸的票「上车」 | 不可以 | **不可以** |
| 进主绩效 | 否（影子侧可记） | 否（`excludedFromPerformance`） |
| 何时升格 | 已是基线 | Y1 证据充分后再议是否并入 A |

## 7. LLM 理由约束（产品要求 · 尽量压空话）

Final Board / 辩论侧车凡产出「理由」，须尽量满足：

| 字段 | 要求 |
|------|------|
| `holdingPeriod` | 持有期（可核对的区间或交易日数） |
| `trigger` | 入场/关注触发条件（可观察） |
| `expectation` | **可证伪**的预期（价格/相对基准/事件结果） |
| `invalidation` | 失效条件（什么出现则论点作废） |

约束手段：prompt 模板 + Skill 配方 + 结构化 JSON 字段校验；空口号、缺字段 → degrade / 落选解释，**不进**绩效。LLM **不能**覆盖硬闸。细节入口见仓库根 [`README.md`](../../README.md)「LLM 理由约束」节。

## 11. 已知现象：S1 / S5 结构性 0 席（仲裁偏置，待签核）

> 状态：**已离线对照（见 §11.5）→ 维持 D**。改仲裁规则 / 优先级 / 席位分配属于口径变更，须你签核并先写 ADR；出厂默认仍为 D，实验开关仅供回测。

### 11.1 现象与证据

walk-forward 回测（2021-01-04 ~ 2026-11-05，`local/shadow/backtest/shadow_backtest.json` 的 `shadow.schoolCoverage`，402 个评估日，`avgBoardSize=10.0`）：

| 学校 | 非空池天数 | 入榜席位（累计） |
|------|-----------|------------------|
| S3 | 402 | 2980 |
| S4 | 402 | 1037 |
| S5 | 402 | **3** |
| S2 | 0 | 0（无历史 DI，见 §12） |
| S1 | **235** | **0** |

S1 有 235 天给出了候选，却一席未进。所以它不是缺数据，是被仲裁挤掉的。

生产日 2026-11-04 实跑复核：S3/S4/S5 各 8 只进 Round2，硬闸后终榜 2 席（全 S3）；22 只落选全是「行业/主题集中度上限」（S3×6、S4×8、S5×8）。S1 当日因截面宽度 17% < 地板 35% 空池，这一天属于正常的择时关闭。

### 11.2 根因（`shadow_board/round2.py::apply_round2_set_a`）

1. 排序键是 `(学校优先级, -score, code)`。**学校优先级排在分数前面**，因此 S3 全部候选都先于 S4，S4 全部先于 S5……S1 永远最后。
2. 之后按序逐个过 `MAX_PER_INDUSTRY=2` 与 `MAX_BOARD_SIZE=10`。S3、S4 每校上限 8（`top_k`），合计 16 只，足够填满 10 席。轮到 S5/S2/S1 时席位已满，原因记为「席位上限」或「集中度上限」。
3. 契约 §2 原意是「**同票冲突**时高优先级胜」，实现却把优先级用作**全局入榜顺序**。这超出了同票去重，变成了席位分配权。

结论：S1 0 席、S5 近 0 席是**仲裁设计造成的结构性偏置**，换数据不会消失。即使 S2 接入数据，在现有规则下也会排在 S3/S4/S5 之后，大概率同样 0 席。

### 11.3 可选改法（均需签核 + ADR；建议先在回测里 A/B）

| 方案 | 做法 | 优点 | 风险 |
|------|------|------|------|
| **A. 只在同票冲突用优先级**（贴合契约原文） | 去重后按 `score` 全局排序（或分校 z-score 标准化后排序），再走集中度 / 席位上限 | 改动最小，与契约字面一致 | 各校分数量纲不同，需先标准化，否则高分校仍垄断 |
| **B. 每校保底席位** | 每个非空池学校先保留 `min_seats`（如 1），剩余席位再按优先级 + 分数分配 | 保证每校都有前向样本可评估 | 弱校保底会稀释组合质量；空池学校不保底（不 pad） |
| **C. 按校配额** | 固定配额（如 S3:3 / S4:3 / S5:2 / S2:1 / S1:1），未用满的配额按优先级回流 | 可控、可解释，便于分校绩效对比 | 配额本身是新参数，需回测选定 |
| **D. 维持现状** | 不改；S1 只作为「择时闸」影响整板开关，不独立出票 | 零改动 | S1/S5 前向账本永远无样本，无法评估 |

建议：先离线回测 A（含分校标准化）与 B（`min_seats=1`），各出一份 `shadow_backtest.json` 对照现状。看总收益、夏普，以及 `schoolCoverage` 中 S1/S5 的席位和分校绩效，再决定是否起 ADR。无论选哪个，都不得 pad-to-N：空池学校不占席位。

### 11.4 S1 自身的改进方向（与仲裁独立）

- 当前 S1 只用截面宽度（地板 35%）做择时，择时打开后按流动性加轻度 `rs20` 排序选股，选股 alpha 很薄。
- 可选：注入 `index_bars`（沪深300/中证500 MA20，`daily_price` 已有指数行时只读即可），让择时口径与回测对齐；或把 S1 改为**整板开关 / 仓位系数**（影响其他校席位上限），不再独立出票。这同样是口径变更，需签核。

### 11.5 离线对照结果（2026-11-06）：A、B 均劣于 D → 维持 D，不起 ADR

实验开关：`apply_round2_set_a(..., arbitration="d"|"a"|"b", min_seats=1)`；CLI `stock-platform-shadow-board --backtest --arbitration a|b|d [--min-seats N]`。**出厂默认仍是 `d`**，不传参时 payload 逐位不变（单测 + 2000 组随机池与改动前实现逐位比对）。硬闸（ST / 流动性 / 涨停 / 行业集中度 / 席位上限）三种模式同一份代码；保底席位只能从已过硬闸的票里取，被行业上限挡住时校内顺延，不放行。

口径：

- **A**：优先级只用于同票去重；入榜按**校内分位** `(n−i)/n` 降序，再按优先级、code。选分位而非 z-score：每校池只有 `top_k=8`，z-score 易被单个离群值主导，分位只依赖各校自己给出的顺序，且与原始分数量纲无关。
- **B**：每个非空池学校先占 `min_seats=1` 席，且**放在榜首**（按优先级顺序）；剩余席位按 D 规则。放榜首是因为回放引擎每天只买榜单前 `max_picks_per_day=8` 只，放榜尾等于没给。
- 数据：2021-01-04 ~ 2026-11-05，只读 `a-stock-engine/data_cache/market.db`，`initial_capital=50000`、`max_positions=15`、`top_k=8`，同一 `book_replay` 引擎；三次运行的 lvrev 基线完全一致。产物 `local/shadow/backtest/shadow_backtest{,_a,_b}.json`（不提交）。D 的结果与 2026-11-05 旧产物逐位一致。

| 指标 | lvrev 基线 | D（现状） | A（校内分位） | B（每校保底 1 席） |
|------|-----------|-----------|---------------|--------------------|
| 总收益 | 47.24% | 10.37% | −25.32% | −29.14% |
| 年化 | 7.14% | 1.77% | −5.07% | −5.95% |
| 最大回撤 | −18.91% | −27.83% | −40.88% | −44.57% |
| 夏普 | 0.559 | 0.198 | −0.217 | −0.300 |
| 胜率 | 44.40% | 42.86% | 32.87% | 33.48% |
| 成交笔数 | 563 | 574 | 727 | 678 |
| 年换手（次） | 100.30 | 102.30 | 129.60 | 120.80 |
| 平均持有日 | 34.7 | 36.4 | 28.8 | 30.8 |
| 空榜比例 | — | 0%（0/402） | 0%（0/525） | 0%（0/469） |

分校：入榜席位 / 实际成交（含未平仓）/ 已平仓胜率 / 已平仓均净收益：

| 学校 | D | A | B |
|------|---|---|---|
| S1 | 0 / 0 / – / – | 560 / 72 / 21.1% / −4.13% | 262 / 63 / 20.6% / −3.71% |
| S2 | 0（恒空池） | 0 | 0 |
| S3 | 2980 / 580 / 43.4% / +0.52% | 1751 / 376 / 44.5% / +0.89% | 3227 / 439 / 42.4% / +0.73% |
| S4 | 1037 / 9 / 11.1% / −7.67% | 1466 / 209 / 17.3% / −2.28% | 729 / 142 / 14.8% / −3.34% |
| S5 | 3 / 0 / – / – | 1473 / 85 / 31.0% / −0.70% | 472 / 49 / 27.1% / −3.73% |

解读：

1. 偏置确实被修掉了：A/B 下 S1/S5 都拿到了席位和真实成交，§11.2 的诊断成立。
2. 但被放进来的票本身是亏的：S1、S4、S5 已平仓均净收益全为负，胜率 15%–31%。D 里 S4 有 1037 席却只成交 9 笔（榜首被 S3 占满，引擎每日只买前 8 只），所以 D 的收益几乎就是「S3 单校」。A/B 把弱校的亏损票换进仓位，组合收益、夏普、回撤全面变差。
3. 席位 ≠ 成交：「评估日」A/B 更多（525/469 vs 402），是因为弱校票更快触发止损离场、仓位更常有空位，换手随之上升。
4. S3 自身在 A 下单笔均收益反而更高（+0.89%），说明问题不在 S3 被挤，而在其他校的薄规则缺选股 alpha。

**结论：维持 D，不建议起 ADR 改仲裁口径。** 理由：A/B 都没有改善组合质量，反而大幅劣化；改仲裁只是把弱信号放进仓位，不产生 alpha。S1/S5 0 席的根本问题是这两校的薄规则本身选股能力差（§11.4），不是席位分配。若只是想要 S1/S5 的前向样本用于评估，应在影子账本里**分校独立记账**（不占终榜席位、不进组合），而不是改终榜仲裁。这同样是口径变更，需另行签核。

未验证 / 局限：只跑了全区间单窗，未做分年或 Y1 3×1y 分窗；B 只试了 `min_seats=1`，A 只试了分位标准化（未试 z-score）；`name` / `industry` 仍是 fundamentals 当前快照（非 PIT）；S2 无历史 DI，结论不覆盖 S2 接入后的情形。差距幅度（夏普 0.198 → −0.22/−0.30）远大于这些局限通常带来的误差，所以「A/B 不优于 D」的方向判断应当稳健；但没有为证明这一点去额外挑区间或调参数。

### 11.6 S1 大势闸门实验（2026-11-06）：gate/empty 全面优于 D，但仍不及 lvrev

实验开关：`stock-platform-shadow-board --backtest --s1-mode pick|gate|scale [--s1-gate-weak empty|s3] [--s1-scale 强,中,弱]`；库函数 `compare_shadow_vs_lvrev / run_shadow_book(..., s1_mode=...)`。**出厂默认仍是 `pick`**，不传参时 board / payload 逐位不变（`test_shadow_board_s1_mode.py` 钉住，并与 §11.5 的 D 产物逐位一致）。lvrev 臂不受开关影响（四次运行 lvrev 指标完全相同）。未改 `book_replay` 引擎。

口径：

- **regime 判定**（`schools.s1_regime_state`）：沿用 S1 现有截面宽度测量（流动性达标票中 `close ≥ MA20` 的比例，可测行 ≥ 5），只用当日截面，PIT。宽度 `< 35%` → `weak`（即 S1 现有择时关闭地板）；`≥ 50%` → `strong`；之间 → `mid`；可测行不足 → `unknown`，按弱处理（fail-closed）。50% 是事先取的中线，未调参。
- **gate**：S1 不出票，席位按 D 规则释放给其他校。`weak/unknown` 日：`empty` = 空榜（不买新票，已有持仓照常按退出规则管理）；`s3` = 只放 S3。
- **scale**：S1 不出票；当日持仓上限 `cap = floor(系数 × max_positions)`，系数 强 1.0 / 中 0.5 / 弱 0（unknown 同弱）。由 entry provider 只返回 `cap − 已持仓` 只（跳过已持仓代码），单仓仍为 `equity / max_positions`，所以低系数 = 少投资金。不强卖已有持仓。
- 数据与参数同 §11.5：2021-01-04 ~ 2026-11-05，只读 market.db，`initial_capital=50000`、`max_positions=15`、`top_k=8`、仲裁 D。产物 `local/shadow/backtest/s1mode/`（不提交）。

regime 状态分布（全部 1414 个交易日）：strong 642（45.4%）/ mid 332（23.5%）/ weak 440（31.1%）/ unknown 0。

解读：

1. **S1 当闸门比当选股校有用**。gate/空榜 相比 D：总收益 10.37% → 27.11%，夏普 0.198 → 0.378，回撤 −27.83% → −24.45%，换手更低。S3 单笔均净收益从 +0.52% 升到 +0.98%：弱势日不开新仓，避开了一批亏损入场。这符合「顺水推舟」的直觉。
2. **弱势日只放 S3 反而比 D 更差**（6.13% / −29.67%）。弱势日的问题是大势本身，换成「防守」校并不能躲开；要躲就得不开仓。
3. **scale 最差**。和 gate/空榜 相比，它多砍了 mid 日的仓位（cap 7/15），而 mid 日入场恰恰是赚的；同时满仓上限更低，S3 好票常被挡在门外（604 个 cap 满日）。回撤略好于 D，但收益几乎归零。
4. **仍不及 lvrev**：最好的 gate/空榜 总收益、夏普、回撤都还落后 lvrev（47.24% / 0.559 / −18.91%）。影子终榜的根本差距在选股（§11.5），闸门只是减少了在逆风里出手。

**结论：gate / 弱日空榜 是唯一在每项主指标上都优于 D 的变体，建议起 ADR 并改出厂默认（影子链 `s1_mode=gate`、`s1_gate_weak=empty`）。** 前置条件：起 ADR 前先补分年 / Y1 3×1y 分窗复核，确认优势不是集中在单一年份。这只改影子终榜，不涉及出厂 lvrev。scale、gate/只放 S3 不建议采用。本节**未改出厂默认、未写 ADR**，等你签核。

事后选择风险：共试 3 个非出厂变体，每个只跑了一组参数（35% 地板沿用 S1 现值；50% 强势线和 1/0.5/0 系数事先给定，未搜索）。从 3 个里挑最好的一个，本身有轻度的事后选择偏差；gate/空榜 对 D 的夏普差距（+0.18）幅度尚可，但回撤改善只有 3.4pp，不算大。

未验证 / 局限：全区间单窗，未分年；regime 只用截面宽度，未接指数 MA（§11.4）；scale 未试其他系数，也未试「缩单仓金额」的形式（那需要改引擎）；`name` / `industry` 仍是当前快照（非 PIT）；S2 无历史 DI。

### 11.7 gate / 弱日空榜 替代 D 的复核（通过标准先于跑数登记，2026-11-06）

> 本节标准在跑分年 / Y1 分窗**之前**写定并单独 commit，结果出来后不改标准、不挑区间、不调参。

候选：`s1_mode=gate`、`s1_gate_weak=empty`（下称 gate）。对照：D（`s1_mode=pick`，出厂）。参数同 §11.6：`initial_capital=50000`、`max_positions=15`、`top_k=8`、仲裁 D，只读 market.db。

**通过标准（三条全部满足才算通过）：**

- **(a) 分年夏普**：2021–2026 六个自然年中，至少 4 年 gate 夏普 ≥ D 夏普。
- **(b) 收益不集中**：单一年份对「gate 相对 D 总超额收益」的贡献 ≤ 60%。
- **(c) Y1 分窗**：`stock-platform-strategy-adoption --include-shadow --windows 3 --years 1` 下，gate 通过的窗口数 ≥ D 通过的窗口数（两者都按现行 `AdoptionRule` 默认阈值、对同一 lvrev 基线判定）。

**口径（事先定）：**

- 分年数据取自 §11.6 同一次全区间回放（2021-01-04 ~ 2026-11-05）的权益曲线与成交，按自然年切分，不做每年冷启动。2026 年为截至 2026-11-05 的不完整年份，照常计入。
- 年收益 = 当年末权益 / 上年末权益 − 1（2021 年以初始资金为分母）；年内最大回撤、夏普（年化、rf=0、日收益，首日收益相对上年末权益）只用当年日收益计算，公式同 `portfolio.compute_metrics`。
- 胜率、成交笔数按**平仓日**所在年份归属已平仓成交。
- (b) 中「年超额」= gate 年收益 − D 年收益；贡献 = 该年超额 / 六年超额之和。若六年超额之和 ≤ 0，(b) 直接判不通过；最大的单年贡献 > 60% 即不通过。
- Y1 分窗如 CLI 不能透传 `s1_mode`，以最小改动加透传参数（默认行为逐位不变，加单测），不改 `AdoptionRule`。
