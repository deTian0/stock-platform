# 0094 — lvrev 实验退出：移动止盈（`trail_tp`）

- **状态**：Proposed（等用户签核）
- **日期**：2026-11-06
- **相关**：计划 [`../plans/lvrev-enhancement.md`](../plans/lvrev-enhancement.md) · 契约 [`../contracts/trading-rules.md`](../contracts/trading-rules.md) · ADR [`0093`](0093-multi-strategy-shadow-board.md)

---

## 背景

多策略影子终榜全面跑输出厂 lvrev（计划 §11.5–§11.8）。转而在 lvrev 本身做五变体增强实验（Round2 二轮 / 大势闸 / 分档止损 / 移动止盈 / 时间止损）。通过标准在跑数前登记于 [`lvrev-enhancement.md`](../plans/lvrev-enhancement.md) §2；N=5 存在多重比较偏差，任一条不满足即不通过。

## 决策（Proposed）

1. **采纳变体 `trail_tp`**：在出厂退出链中，硬止损之后、出厂其余分支之前，增加实验分支——峰值收益 ≥ +8% 后，自峰值回撤 ≥ 5% 即离场；**不受 `min_hold` 限制**。理由字符串 `trail_tp(...)`。
2. **实现**：`ExitPolicy.trail_tp: bool = False`（出厂默认关）；开启时走上述分支。参数事先写死，不做搜索。
3. **签核前不改出厂默认**：库默认、日循环、brief / picks 仍用 `ExitPolicy()`；仅实验开关 / CLI `stock-platform-lvrev-enhancement` 可打开。
4. **签核后若 Accepted**：再另开提交把生产默认改为 `trail_tp=True`（或等价配置），并更新契约「出厂默认」叙述；本 ADR 不自动改默认。

## 证据（2021-01-04~2026-11-05，只读 market.db）

| 指标 | lvrev 基线 | `trail_tp` |
|------|-----------|------------|
| 总收益 | 47.24% | 74.50% |
| 最大回撤 | −18.91% | −18.58% |
| 夏普 | 0.559 | 0.779 |
| 胜率 | 44.40% | 52.24% |
| 年换手 | 100.3 | 119.4 |
| 成交笔数 | 563 | 670 |

通过标准：

- (a) 分年夏普 ≥ 基线 **5/6** 年（唯 2021 未过）
- (b) 单年超额贡献最大 **51.53%**（2024）≤ 60%
- (c) Y1 3×1y 通过窗 **3 ≥ 0**（基线自比）
- (d) 最大回撤 −18.58% ≥ −18.91%

其余四变体均不通过（见计划 §5）；本 ADR **只**覆盖 `trail_tp`。

## 非目标

改 `W_DEFAULT` / `min_pick_score`；开 live；把 Round2 / regime / 其他退出变体一并升默认；伪造指数超额。

## 后果

**正面**：事先标准下唯一通过的增强；全区间收益与夏普明显优于基线，回撤不更深。  
**代价 / 风险**：N=5 多重比较偏差；换手上升；2021 年夏普低于基线；峰值阈值（+8% / 回撤 5%）未经搜索，换参可能改变结论。签核时应显式接受这些局限。
